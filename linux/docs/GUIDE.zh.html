1. 开始使用

Zetalvx Image Lab — Qwen 2.1 Edition 使用 Qwen Image 2.1 生成、编辑和组合图片。

  1. 创建第一个账户；从其他设备访问时，输入服务器显示的临时配对码。
  2. 在模型 → 我的模型中关联完整的 Qwen 仓库，或关联仓库并指定兼容的替代 Transformer。
  3. 保存并检查组件。就绪表示文件检查通过，不表示已成功测试生成。
  4. 创建或打开项目。在创建 / 编辑中输入提示词，按需添加图片，先尝试 1024 × 1024 等尺寸。

文件路径属于运行应用的服务器，而非手机。安装包不包含模型权重。

2. 导航与移动端菜单

底部栏的首页、创建 / 编辑、图库、更多均匀占满宽度。更多包含模型、工具、预设、项目、任务、指南和设置；打开这些次级页面时，更多保持高亮。

点击关闭、面板外区域或按 Esc 关闭菜单。Tab 焦点保持在打开的面板内。模型页标签也支持方向键、Home 和 End。

在图像卡片上，添加为输入会把图像加入有序的 Qwen 输入。复用设置会把该结果的提示词和生成参数恢复到创建/编辑页面，供你修改后自行启动新任务。这两个操作都不会开始生成。更多操作包含详情、编辑 / 工具、保存 PNG 和删除。

指南包含十五项紧凑索引和单篇文章。可用当前语言搜索，选择主题，通过上一项、下一项或全部主题导航，不再重复显示第二份列表。

3. 生成与编辑

使用同一工作区：没有附件时从文本生成；一个附件用于编辑或参考；多个附件用于组合有序参考图。明确说明哪些内容要改变、哪些应保留。附件位于提示词附近，表单下直接显示队列和历史，不再重复显示预览图。

种子 -1表示随机，0 也是有效种子。初始设置仍为 40 步，True CFG 关闭。高级设置包括尺寸、批量、CFG/负面提示词、单任务 Transformer 和解码选项。

每个任务入队时保存自己的设置。批量会创建独立任务；刷新页面不会取消服务器任务。取消活动任务请使用取消按钮。复用设置只填写表单，提交后才会生成。

要进行可重复比较，应保持提示词、种子、尺寸、组件、精度和解码设置一致。更换种子不能单独比较解码器的影响。

4. 附件与透明 PNG

在提示词附近，最多可从设备或图库添加10 张图片。显示顺序即发送给 Qwen 的顺序：在提示词中使用 “Image 1”、“Image 2” 指代。箭头用于排序；移除附件不会删除图库文件。输入图片归属于项目。

请求透明 PNG（RGBA）会请求透明背景，并保留模型实际返回的 Alpha。棋盘格显示透明区域；图片里画出的深色背景不等于透明。如果结果不透明，应用会提示，不会偷偷调用外部抠图模型。

在图像卡片上，添加为输入会把图像加入有序的 Qwen 输入。复用设置会把该结果的提示词和生成参数恢复到创建/编辑页面，供你修改后自行启动新任务。这两个操作都不会开始生成。更多操作包含详情、编辑 / 工具、保存 PNG 和删除。

5. 仓库、Transformer 与目录

Diffusers指按组件组织的仓库；GGUF和 safetensors 可替换 Transformer。单个 GGUF 并不是完整模型：仍需配置、processor/tokenizer、文本编码器、调度器和兼容 VAE。

在我的模型中指定主目录及可选替代文件。检查以紧凑摘要显示；展开文件与兼容性详情查看路径。首次显示缺失文件时会自动展开详情。

所有已链接、上传或下载的内容都会显示在这里以及上方的选择器中。 选择已链接、上传或下载的组件。所选路径显示在下方。 已在表单中选择组件。请保存配置，或将其保存为模型配置方案。

保存前检查下一任务将使用哪个 Transformer：创建 / 编辑中的单任务替代选项可优先于模型全局配置。

6. VAE、解码器与其他组件

从“可用组件”中选择兼容组件，或保留基础仓库的默认组件。 选择已链接、上传或下载的组件。所选路径显示在下方。

解码器属于 VAE，不支持任意混搭神经网络层。建议使用完整 Diffusers VAE 文件夹；单文件必须有匹配的原生键和配置。ComfyUI 转换文件不自动视为等价。

64 × 64 CPU VAE 测试会严格检查权重、尺寸，以及 RGBA 编码/解码循环中的数值是否有限。它不认证画质，也不验证 2048 尺寸所需内存。恢复官方组件只修改表单，保存后才应用。

Texture-Fix 是需要核查的可选来源，不随包附带。其按钮打开下载流程，请阅读权重条款。调度器的静态偏移会关闭动态偏移；留空可保持原采样器。

编码器权重

INT8 ConvRot 使用可选浮点重建，而非原生 INT8 内核。这不是原生 INT8 速度或 VRAM 测试。

原生 ConvRot：对于受支持的 Qwen 2.1 Transformer/Text Encoder 单文件 safetensors，Benchmark Lab 可使用现有且已验证的 ComfyUI 运行环境，无需 Image Lab 浮点重建。原生 T2I 需要显式单文件 Transformer、Text Encoder 和 VAE。不支持的组合只会使该任务失败，其余批次继续。浮点重建仍是独立的质量/调试模式，其耗时和 VRAM 不代表原生 INT8 性能。

7. 模型配置与 LoRA

模型配置保存组件、Transformer、精度、内存、解码设置和 LoRA 列表，不复制权重。保存、启用、复制、导入/导出和删除互相独立；保存不会启用，启用需确认。

已经入队的任务不会被重新配置。分享 JSON 前检查本地路径；配置中不包含账户令牌。

LoRA 必须明确兼容 Qwen Image 2.1。可设置最多四个适配器的顺序与权重，应用会检查运行环境能力。未启用 LoRA 与 GGUF 组合，不会静默忽略。

提示词预设与模型配置独立：模型配置选择组件和资源，预设恢复创作设置。

9. Decode Lab、潜变量与显存

启用保留潜变量时，会在解码前保存准确的 VAE 输入张量。采样结束后释放不需要的模型，再由 VAE 单独解码。下次生成可能需要重新加载这些模型。

若采样结束后 GPU 解码内存不足，打开结果下方的 Decode Lab，选择已保存潜变量、CPU和整帧，再解码。此操作需要零个采样步骤，但需要系统内存，可能较慢；不保证所有机器都能成功解码 2048。

自动和整帧不会自动切换到分块或 CPU。标准及自定义分块仅为手动实验，可能重新出现线条或伪影。重叠 = 块大小 − 步幅。

可在同一个潜变量上比较官方与自定义 VAE。潜变量会作为持久实验数据保存，应用不再限制数量或总大小；实际限制是磁盘可用空间。Decode Lab 会显示已用空间和剩余空间。只有在不再需要精确重复 VAE 解码时才删除记录；PNG 图像会保留。

测试实验室

受控对比，每次运行一个 GPU 任务。

使用“创建／编辑”的提示词、有序输入图、种子、分辨率、步数和引导参数。整个对比只生成一次随机种子。

确认并将全部测试入队

使用所选输出分辨率。确定性 VAE 编码，各轮之间使用 RGBA8，不进行扩散。指标与调整大小后的原图比较。

耗时包括组件加载。可用时分别记录采样、卸载和解码。内存值仅涉及此工作进程，不代表整块 GPU 或整个系统。

相同种子不能保证不同实现的输出完全一致。还需目视检查质量及身份保留情况。

10. 图库、项目与队列

每个项目拥有自己的图片与任务。图库选择器和项目卡片用于切换当前项目；模型设置在安装实例内共享。

卡片显示标题、显示编号、可用时的日期/种子以及短 ID。编号跟随项目排序，删除后可能改变；ID 才是资源身份。新布局不重命名文件。

更多操作 → 详情显示原始参数。项目回收站可恢复；永久删除会清除项目数据，包括潜变量。请先保存需要的结果。

任务页显示阶段和进度。取消针对单个任务；清空等待队列不会中断正在运行的任务。

11. 图片工具与 FFmpeg

工具保留缩放、格式转换、裁剪、旋转和翻转。选择一个或多个资源，确认参数后执行，新结果保存至项目。

视频 · 帧允许上传视频并选择首帧、末帧或指定时间。先查看 FFmpeg 预览，保存的 PNG 来自服务器预览，并非浏览器播放器截图。

浏览器播放取决于格式；不支持播放时可尝试指定时间。等待预览完成后再保存。切换项目会清除前一视频选择。此页面用于提取帧，不生成 Qwen 视频。

12. 下载与 HF / Civitai 账户

模型页包含添加、下载和账户。使用远程来源时，粘贴链接，选择组件类型，点击检查，核查来源、条款和大小后确认下载。Texture-Fix 只预填来源。

浏览器上传仅支持单个权重文件。完整仓库、文本编码器、处理器和调度器都是文件夹：请从服务器链接或从 Hugging Face 下载。 所有已链接、上传或下载的内容都会显示在这里以及上方的选择器中。

确认后的下载在服务器上继续；从设备上传需要保持页面打开。传输期间请勿更新或卸载。

账户使用 HF/Civitai 令牌，而非平台密码。令牌保存在服务器，不进入预设。从应用删除令牌不会在平台撤销它。请勿分享 secrets 或包含私人数据的报告。

Apache-2.0 适用于应用代码。权重、LoRA 和 VAE 有独立条款，可能限制商业使用。由用户另外下载不会消除这些义务。加入目录不构成使用权认证。

13. 访问、网络与设置

Linux 数据目录仍为 ~/.local/share/ImageLabQwen21。本地监听 127.0.0.1；局域网允许同一网络中的其他设备访问。默认端口为 8298。不要在同一端口启动其他应用，也不要直接将本服务暴露到互联网。

HTTPS 保持开启。远程创建首个账户需要服务器显示的临时代码，有效期 20 分钟。使用 imagelab-qwen setup-code获取新代码；这不是已有账户的密码恢复方式。

设置管理账户、网络及桌面快捷方式。网络更改保存后需重启。界面配色仅保存在浏览器，不改变图片。

14. 更新、启动与卸载

从 1.0.27 更新至 1.0.28：结束任务和传输，打开设置 → 更新，导入完整 Linux ZIP，并确认来源和密码。不要解压后重新打包更新 ZIP。操作在服务器继续，请勿另开安装程序；重启后核查版本 1.0.28。

此界面修订不改变依赖。已验证的运行环境可复用，但安装程序仍执行检查。回滚返回上一版本并保留数据。

命令：imagelab-qwen start、imagelab-qwen stop、imagelab-qwen status、imagelab-qwen setup-code。无浏览器启动：imagelab-qwen start --lan --no-browser。不在 PATH 时使用 ~/.local/share/ImageLabQwen21/bin/imagelab-qwen。

卸载默认保留数据；明确选择完全删除会连同内部模型和数据一起移除，请先备份。关联的外部路径不会删除。ZIP 中的历史技术标识用于更新兼容，请勿手动改名。

15. 诊断与常见问题

采样后 OOM：检查潜变量是否保存，再明确尝试 CPU 整帧解码。不要为隐藏错误而静默改为分块，因为可能产生伪影。内存峰值受尺寸与组件影响，不只是权重大小。

紫色条纹：使用自动/整帧，并在同一潜变量上比较 VAE。仅更换 VAE 不保证解决问题。

模型就绪但生成失败：查看任务 → 详情，以及模型页运行环境诊断。文件检查不能证明运行环境或 GPU 已成功执行测试。

旧界面：服务重启后刷新页面，检查顶部版本。指南搜索仅搜索指南文字，不搜索提示词或图片。

日志位于 Qwen 数据目录的 shared/logs，安装报告在 shared/audits。分享相关错误与设置即可，不要分享令牌、密码或整个私人目录。

16. 自动 Benchmark Lab

Benchmark Lab 通过与普通生成相同的串行 GPU 队列运行受控批量测试。选择测试套件和基准模型预设，然后选择已经在模型目录中登记的 Transformer、编码器或 VAE 进行比较。

Transformer 质量和编码器指令遵循提供现成测试提示词，默认使用 1024 × 1024、30 步和种子 314159。矩阵会组合所选 Transformer 与编码器。VAE 对比可解码同一个已保存 latent，也可执行确定性的 1×/5×/10× 往返测试。

在准备批次生成可检查的计划并由你确认之前，不会启动任何任务。结果会记录总时间、加载、sampling、decode、CUDA allocated/reserved 峰值、进程 RAM 峰值、所选组件和输出图像，并可导出 JSON 或 CSV。

组件来自模型页面；Benchmark 不会从文件系统猜测文件。只需添加或链接一次组件，之后即可在批次中选择。

原生 ConvRot：对于受支持的 Qwen 2.1 Transformer/Text Encoder 单文件 safetensors，Benchmark Lab 可使用现有且已验证的 ComfyUI 运行环境，无需 Image Lab 浮点重建。原生 T2I 需要显式单文件 Transformer、Text Encoder 和 VAE。不支持的组合只会使该任务失败，其余批次继续。浮点重建仍是独立的质量/调试模式，其耗时和 VRAM 不代表原生 INT8 性能。
