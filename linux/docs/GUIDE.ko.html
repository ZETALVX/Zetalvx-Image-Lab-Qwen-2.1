Zetalvx Image Lab — Qwen 2.1 Edition

1.0.75 · 한국어

시작하기 탐색과 모바일 메뉴 생성과 편집 첨부와 투명 PNG 저장소, Transformer와 목록 VAE, 디코더와 구성 요소 모델 프로필과 LoRA 사용자 프리셋 Decode Lab, 잠재 텐서와 메모리 라이브러리, 프로젝트와 대기열 이미지 도구와 FFmpeg 다운로드와 HF / Civitai 계정 접근, 네트워크와 설정 업데이트, 시작과 제거 진단과 일반적인 문제 자동 Benchmark Lab

1. 시작하기

Zetalvx Image Lab — Qwen 2.1 Edition은 Qwen Image 2.1로 이미지를 생성, 편집, 결합합니다. 이 Linux 버전에는 구성 요소, 프리셋, 모델 프로필, Decode Lab이 유지됩니다.

  1. 첫 계정을 만드세요. 다른 기기에서는 서버에 표시된 임시 설정 코드를 입력합니다.
  2. 모델 → 내 모델에서 전체 Qwen 저장소, 또는 저장소와 호환되는 대체 Transformer를 연결합니다.
  3. 저장하고 구성 요소를 검사합니다. 준비됨은 파일 검사 통과를 뜻하며 생성 성공을 보장하지 않습니다.
  4. 프로젝트를 만들거나 열고 생성 / 편집에서 프롬프트를 작성한 뒤 필요한 이미지를 첨부합니다. 처음에는 1024 × 1024 등으로 시험하세요.

경로는 휴대폰이 아닌 서버의 경로입니다. 모델 가중치는 패키지에 포함되지 않습니다.

2. 탐색과 모바일 메뉴

하단의 홈, 생성 / 편집, 라이브러리, 더 보기가 전체 너비에 균등하게 배치됩니다. 더 보기에는 모델, 도구, 프리셋, 프로젝트, 작업, 가이드, 설정이 있으며 보조 페이지에서는 더 보기가 강조됩니다.

닫기, 패널 바깥 터치, Esc로 메뉴를 닫습니다. Tab은 열린 패널 안에서 이동합니다. 모델 탭은 방향키와 Home, End도 지원합니다.

이미지 카드에서 입력에 추가는 이미지를 순서가 있는 Qwen 입력에 추가합니다. 설정 재사용은 해당 결과의 프롬프트와 생성 설정을 생성/편집 화면에 복원해 수정한 뒤 직접 새 작업을 시작할 수 있게 합니다. 두 작업 모두 생성을 시작하지 않습니다. 추가 작업에는 상세 정보, 편집 / 도구, PNG 저장, 삭제가 있습니다.

가이드는 15개 주제의 간결한 목차와 단일 본문을 제공합니다. 현재 언어로 검색하고 주제를 선택한 뒤 이전, 다음, 모든 주제로 이동합니다. 같은 목록을 반복하지 않습니다.

3. 생성과 편집

작업 화면은 하나입니다. 첨부가 없으면 텍스트로 생성하고, 하나면 편집 또는 참조, 여러 개면 순서가 있는 참조 이미지를 결합합니다. 바꿀 부분과 유지할 부분을 명확히 쓰세요. 첨부 영역은 프롬프트 가까이에 있고 대기열과 기록은 양식 아래에 있으며 중복 미리보기는 없습니다.

시드 -1은 무작위이며 0도 유효합니다. 기본값은 40단계, True CFG 끔입니다. 고급 설정에는 크기, 배치, CFG/네거티브 프롬프트, 작업별 Transformer, 디코딩 옵션이 있습니다.

작업은 대기열에 들어갈 때 설정을 보관합니다. 배치는 개별 작업을 만들며 페이지 새로 고침은 서버 작업을 취소하지 않습니다. 실행 중인 작업은 취소 버튼을 사용합니다. 설정 재사용은 양식만 채우고 제출해야 생성합니다.

재현 가능한 비교를 위해 프롬프트, 시드, 크기, 구성 요소, 정밀도, 디코딩을 유지하세요. 시드를 바꾸면 디코더만 따로 비교할 수 없습니다.

프롬프트 개선

생성 전 선택적으로 프롬프트를 개선합니다. 자동 실행되지 않습니다.

기존 로컬 ComfyUI를 별도 프로세스에서 사용합니다. 서버 실행, 설치, 모델 다운로드는 없습니다. 이미지 생성 전에 프로세스가 종료됩니다.

PE 파일 추가 → PE-I2I · 입력 이미지 / PE-T2I · 텍스트만.

기존 ComfyUI 폴더 + 해당 ComfyUI 환경의 Python. 런타임 경로를 확인하고 신뢰를 승인하세요.

다시 쓴 프롬프트 미리보기 → 다시 쓴 프롬프트 · 편집 가능 → 이 프롬프트 사용. 프롬프트만 바뀝니다. 이미지, 시드, 크기 및 생성 설정은 유지됩니다.

512 토큰으로 시작하세요. 토큰 수나 사고 모드를 늘리면 시간과 메모리 사용량이 증가할 수 있습니다.

Image Lab 기본값은 간단한 자체 지침이며 Qwen 공식 system_prompt.txt의 사본이 아닙니다. 테스트할 지침은 사용자 지정에 붙여 넣으세요.

4. 첨부와 투명 PNG

프롬프트 옆에서 기기 또는 라이브러리의 이미지를 최대 10개 첨부합니다. 표시된 순서가 Qwen에 전달되며 프롬프트에서는 “Image 1”, “Image 2”로 지칭합니다. 화살표로 순서를 바꾸며 첨부 해제는 라이브러리 파일을 삭제하지 않습니다. 입력은 프로젝트에 속합니다.

투명 PNG 요청(RGBA)은 투명 배경을 요청하고 실제 반환된 알파를 보존합니다. 체크무늬는 투명 영역을 보여주지만 이미지에 그려진 어두운 배경은 투명이 아닙니다. 불투명 결과는 안내되며 외부 배경 제거 모델을 몰래 실행하지 않습니다.

이미지 카드에서 입력에 추가는 이미지를 순서가 있는 Qwen 입력에 추가합니다. 설정 재사용은 해당 결과의 프롬프트와 생성 설정을 생성/편집 화면에 복원해 수정한 뒤 직접 새 작업을 시작할 수 있게 합니다. 두 작업 모두 생성을 시작하지 않습니다. 추가 작업에는 상세 정보, 편집 / 도구, PNG 저장, 삭제가 있습니다.

5. 저장소, Transformer와 목록

Diffusers는 구성 요소로 나뉜 저장소이며 GGUF와 safetensors는 Transformer를 대체할 수 있습니다. GGUF 하나는 전체 모델이 아닙니다. 설정, processor/tokenizer, 텍스트 인코더, 스케줄러, 호환 VAE가 필요합니다.

내 모델에서 주 폴더와 선택적 대체 파일을 설정합니다. 검사는 간략히 표시되며 파일 및 호환성 상세를 열어 경로를 확인합니다. 누락된 파일은 처음 표시할 때 펼쳐집니다.

연결, 업로드 또는 다운로드한 모든 항목이 여기와 위 선택 목록에 표시됩니다. 이미 연결, 업로드 또는 다운로드한 구성 요소를 선택하세요. 선택한 경로가 아래에 표시됩니다. 폼에서 구성 요소를 선택했습니다. 구성을 저장하거나 모델 프로필로 저장하세요.

저장하기 전에 다음 작업의 Transformer를 확인하세요. 생성 / 편집의 작업별 선택이 전역 모델 설정보다 우선할 수 있습니다.

6. VAE, 디코더와 구성 요소

사용 가능한 구성 요소에서 호환 항목을 선택하거나 기본 저장소의 기본값을 유지하세요. 이미 연결, 업로드 또는 다운로드한 구성 요소를 선택하세요. 선택한 경로가 아래에 표시됩니다.

디코더는 VAE의 일부이며 임의의 레이어 혼합은 지원하지 않습니다. 전체 Diffusers VAE 폴더를 권장합니다. 단일 파일은 네이티브 키와 설정이 맞아야 합니다. ComfyUI 변환본을 자동으로 동일하게 취급하지 않습니다.

64 × 64 CPU VAE 테스트는 엄격한 가중치 일치, 크기, RGBA 인코딩/디코딩의 유한한 값을 검사합니다. 화질이나 2048 메모리 사용량을 인증하지 않습니다. 공식 구성으로 복원은 양식을 바꾸며 저장해야 적용됩니다.

Texture-Fix는 검토할 선택적 출처이며 포함되어 있지 않습니다. 버튼은 다운로드 절차를 열며 가중치 약관을 읽어야 합니다. 스케줄러의 정적 시프트는 동적 시프트를 끕니다. 비워 두면 기존 샘플러를 유지합니다.

인코더 가중치

INT8 ConvRot는 선택적 부동소수점 복원을 사용하며 네이티브 INT8 커널이 아닙니다. 네이티브 INT8 속도나 VRAM 벤치마크가 아닙니다.

네이티브 ConvRot: 지원되는 Qwen 2.1 Transformer/Text Encoder single-file safetensors는 Image Lab의 float 복원 없이 기존의 검증된 ComfyUI 런타임을 Benchmark Lab에서 사용할 수 있습니다. 네이티브 T2I에는 명시적인 single-file Transformer, Text Encoder, VAE가 필요합니다. 지원되지 않는 조합은 해당 작업만 실패하고 나머지 배치는 계속됩니다. float 복원은 별도의 품질/디버그 모드이며 시간과 VRAM은 네이티브 INT8 성능이 아닙니다.

7. 모델 프로필과 LoRA

모델 프로필은 구성 요소, Transformer, 정밀도, 메모리, 디코딩, LoRA 목록을 저장하며 가중치는 복사하지 않습니다. 저장, 활성화, 복제, 가져오기/내보내기, 삭제는 별개입니다. 저장만으로 활성화되지 않으며 활성화에는 확인이 필요합니다.

이미 대기 중인 작업의 설정은 바뀌지 않습니다. JSON 공유 전 로컬 경로를 확인하세요. 계정 토큰은 프로필에 포함되지 않습니다.

LoRA는 Qwen Image 2.1과 명시적으로 호환되어야 합니다. 최대 4개 어댑터의 순서와 강도를 지정하며 런타임 기능을 검사합니다. GGUF와 LoRA 조합은 활성화되지 않았고 조용히 무시하지도 않습니다.

프롬프트 프리셋은 별개입니다. 프로필은 구성 요소와 자원을 선택하고 프리셋은 창작 설정을 복원합니다.

8. 사용자 프리셋

모델 프리셋 / 생성 프리셋 / 전체 프리셋

모델 프리셋은 구성 요소와 로딩 설정을 저장하고, 생성 프리셋은 모델 경로 없이 이미지 매개변수를 저장합니다. 전체 프리셋은 둘 다 저장합니다.

생성 / 편집에서 구성 요소와 매개변수를 조정한 후 여기서 저장하세요. 이미지는 포함되지 않습니다.

체크하면 이 작업에서만 구성 요소를 바꿉니다. 체크하지 않으면 프리셋을 사용하며 필수 모듈을 제거하지 않습니다.

프리셋을 적용했습니다. 작업은 시작하지 않았습니다.

연결 확인 완료. 새 프리셋으로 가져오기를 확인하세요.

프리셋을 삭제하시겠습니까? 모델과 이미지는 유지됩니다.

9. Decode Lab, 잠재 텐서와 메모리

잠재 텐서 보관이 켜져 있으면 VAE에 전달할 정확한 텐서를 디코딩 전에 저장합니다. 샘플링이 끝나면 불필요한 모델을 해제하고 VAE가 별도로 디코딩합니다. 다음 생성에서 모델을 다시 불러올 수 있습니다.

단계가 끝난 뒤 GPU 메모리가 부족하면 결과 아래 Decode Lab을 엽니다. 저장된 잠재 텐서, CPU, 전체 프레임을 선택하고 디코딩합니다. 샘플링 0단계이지만 RAM이 필요하고 느릴 수 있습니다. 모든 장치에서 2048 성공을 보장하지 않습니다.

자동과 전체 프레임은 타일이나 CPU로 자동 전환되지 않습니다. 표준/사용자 타일은 수동 실험이며 줄이나 아티팩트가 다시 나타날 수 있습니다. 겹침 = 타일 크기 − 스트라이드입니다.

같은 latent로 공식 VAE와 사용자 VAE를 비교할 수 있습니다. latent는 장기 실험 데이터로 보존되며 앱이 개수나 전체 크기를 제한하지 않습니다. 실제 한계는 디스크의 남은 공간입니다. Decode Lab에서 사용량과 여유 공간을 확인할 수 있습니다. 동일한 VAE decode를 다시 수행할 필요가 없을 때만 항목을 삭제하세요. PNG 이미지는 유지됩니다.

벤치마크 실험실

조건을 맞춰 비교하고 GPU 작업을 하나씩 실행합니다.

생성 / 편집의 프롬프트, 입력 이미지 순서, 시드, 해상도, 스텝 및 가이던스를 사용합니다. 무작위 시드는 전체 비교에 대해 한 번만 정합니다.

확인 후 모든 테스트 대기열 추가

선택한 출력 해상도를 사용합니다. 결정적 VAE 인코딩과 주기 사이 RGBA8을 사용하며 확산은 없습니다. 크기를 조정한 원본과 지표를 비교합니다.

시간에는 구성 요소 로딩이 포함됩니다. 가능하면 샘플링, 오프로딩 및 디코딩을 따로 기록합니다. 메모리는 전체 GPU나 시스템이 아닌 이 작업 프로세스 기준입니다.

동일한 시드여도 구현이 다르면 동일한 결과를 보장하지 않습니다. 품질과 인물 유지도 눈으로 확인하세요.

10. 라이브러리, 프로젝트와 대기열

각 프로젝트에는 자체 이미지와 작업이 있습니다. 라이브러리 선택기와 프로젝트 카드로 현재 프로젝트를 바꿉니다. 모델 설정은 설치 내에서 공유됩니다.

카드에는 제목, 표시 번호, 가능한 날짜/시드와 짧은 ID가 있습니다. 번호는 프로젝트 순서를 따르며 삭제 후 달라질 수 있고 ID가 자원의 식별자입니다. 새 표시 방식은 파일 이름을 바꾸지 않습니다.

추가 작업 → 상세 정보는 원래 설정을 보여줍니다. 프로젝트 휴지통에서는 복원할 수 있고 영구 삭제는 잠재 텐서를 포함한 데이터를 지웁니다. 필요한 결과는 먼저 저장하세요.

작업에는 단계와 진행률이 표시됩니다. 취소는 한 작업에 적용되며 대기열 비우기는 이미 실행 중인 작업을 중단하지 않습니다.

11. 이미지 도구와 FFmpeg

도구는 크기 변경, 변환, 자르기, 회전, 뒤집기를 유지합니다. 하나 이상의 항목을 고르고 설정을 확인한 뒤 실행합니다. 새 결과는 프로젝트에 저장됩니다.

동영상 · 프레임에서는 동영상을 올리고 첫/마지막 프레임 또는 시간을 지정합니다. FFmpeg 미리보기를 확인하세요. 저장 PNG는 서버 미리보기이며 브라우저 플레이어 캡처가 아닙니다.

재생은 형식에 따라 다릅니다. 지원하지 않으면 시간 지정을 시도하세요. 미리보기가 끝난 뒤 저장합니다. 프로젝트를 바꾸면 이전 동영상 선택이 해제됩니다. 이 페이지는 프레임을 추출하며 Qwen 동영상을 생성하지 않습니다.

12. 다운로드와 HF / Civitai 계정

모델에는 추가, 다운로드, 계정이 있습니다. 원격 출처는 링크를 붙이고 구성 요소 종류를 선택한 뒤 검사하여 출처, 약관, 크기를 검토하고 다운로드를 확인합니다. Texture-Fix는 출처를 채워 넣을 뿐입니다.

브라우저 업로드는 단일 가중치 파일만 지원합니다. 전체 저장소, 텍스트 인코더, 프로세서, 스케줄러는 폴더이므로 서버에서 연결하거나 Hugging Face에서 다운로드하세요. 연결, 업로드 또는 다운로드한 모든 항목이 여기와 위 선택 목록에 표시됩니다.

확인한 다운로드는 서버에서 계속됩니다. 기기에서 업로드할 때는 페이지를 열어 두세요. 전송 중에는 업데이트나 제거를 하지 마세요.

계정에는 플랫폼 비밀번호가 아닌 HF/Civitai 토큰을 사용합니다. 토큰은 서버에 저장되고 프리셋에는 들어가지 않습니다. 앱에서 지워도 플랫폼에서 폐기되지는 않습니다. secrets나 개인 정보가 든 보고서를 공유하지 마세요.

Apache-2.0은 앱 코드에 적용됩니다. 가중치, LoRA, VAE는 상업적 제한을 포함할 수 있는 별도 약관을 가집니다. 따로 다운로드해도 의무가 사라지지 않습니다. 목록 등록은 사용 권한을 인증하지 않습니다.

13. 접근, 네트워크와 설정

Linux 데이터 폴더는 ~/.local/share/ImageLabQwen21입니다. 로컬은 127.0.0.1에서 수신하며 LAN은 같은 네트워크의 다른 기기를 허용합니다. 기본 포트는 8298입니다. 같은 포트에 다른 앱을 실행하거나 서비스를 인터넷에 직접 노출하지 마세요.

HTTPS는 켜져 있습니다. 원격 첫 계정 설정은 서버에 표시되는 20분 유효 코드를 필요로 합니다. imagelab-qwen setup-code로 새로 발급합니다. 기존 계정의 비밀번호 복구 기능이 아닙니다.

설정에서 계정, 네트워크, 바탕화면 바로가기를 관리합니다. 네트워크 변경은 저장 후 재시작해야 적용됩니다. 인터페이스 색상은 브라우저에만 저장되어 이미지를 바꾸지 않습니다.

14. 업데이트, 시작과 제거

1.0.27에서 1.0.28로 업데이트하려면 작업과 전송을 끝내고 설정 → 업데이트에서 전체 Linux ZIP을 가져온 뒤 출처와 비밀번호를 확인합니다. 업데이트 ZIP을 풀고 다시 압축하지 마세요. 서버에서 계속되므로 다른 설치 프로그램을 시작하지 마세요. 재시작 후 1.0.28를 확인합니다.

이 개선은 의존성을 바꾸지 않습니다. 검증된 런타임은 재사용할 수 있으나 설치 검사는 계속합니다. 롤백은 데이터를 유지하고 이전 버전으로 돌아갑니다.

명령: imagelab-qwen start, imagelab-qwen stop, imagelab-qwen status, imagelab-qwen setup-code. 브라우저 없이: imagelab-qwen start --lan --no-browser. PATH에 없으면 ~/.local/share/ImageLabQwen21/bin/imagelab-qwen를 사용합니다.

제거는 완전 삭제를 명시적으로 선택하지 않는 한 데이터를 유지합니다. 완전 삭제는 내부 모델과 데이터도 지우므로 먼저 백업하세요. 연결된 외부 경로는 삭제하지 않습니다. ZIP의 과거 기술 식별자는 업데이트 호환성용이므로 직접 바꾸지 마세요.

15. 진단과 일반적인 문제

단계 후 OOM: 잠재 텐서 보관 여부를 확인하고 CPU 전체 프레임 디코딩을 명시적으로 시도하세요. 오류를 숨기려고 타일로 바꾸지 마세요. 아티팩트가 생길 수 있습니다. 메모리 최대치는 가중치뿐 아니라 크기와 구성 요소에 달려 있습니다.

보라색 줄: 자동/전체 프레임을 사용하고 같은 텐서로 VAE를 비교하세요. VAE 교체만으로 해결을 보장하지 않습니다.

모델 준비됨, 생성 실패: 작업 → 상세 정보와 모델 런타임 진단을 보세요. 파일 검사는 GPU 실행 성공을 증명하지 않습니다.

이전 인터페이스: 재시작 후 새로 고침하고 상단 버전을 확인하세요. 가이드 검색은 가이드만 검색하며 프롬프트나 이미지는 검색하지 않습니다.

로그는 Qwen 폴더의 shared/logs, 설치 보고서는 shared/audits에 있습니다. 관련 오류와 설정만 공유하고 토큰, 비밀번호, 개인 폴더 전체는 공유하지 마세요.

16. 자동 Benchmark Lab

Benchmark Lab은 일반 생성과 동일한 직렬 GPU 큐에서 조건을 고정한 배치 비교를 실행합니다. 테스트 스위트와 기준 모델 프리셋을 선택한 뒤 이미 등록된 Transformer, encoder 또는 VAE 중 비교할 항목을 고릅니다.

Transformer 품질과 Encoder 지시 준수에는 준비된 테스트 프롬프트가 있으며 기본값은 1024 × 1024, 30 steps, seed 314159입니다. Matrix는 선택한 Transformer와 encoder를 조합합니다. VAE는 같은 보존 latent를 decode하거나 결정론적 1×/5×/10× round-trip을 실행할 수 있습니다.

배치 준비로 검토 가능한 계획을 만들고 확인하기 전에는 아무 작업도 시작되지 않습니다. 결과에는 총 시간, 로딩, sampling, decode, CUDA allocated/reserved 피크, 프로세스 RAM 피크, 선택한 구성 요소와 출력 이미지가 기록됩니다. JSON 또는 CSV로 내보낼 수 있습니다.

구성 요소는 모델에서 가져오며 Benchmark가 파일 시스템에서 임의로 추측하지 않습니다. 한 번 추가하거나 연결한 뒤 배치에서 선택하세요.

네이티브 ConvRot: 지원되는 Qwen 2.1 Transformer/Text Encoder single-file safetensors는 Image Lab의 float 복원 없이 기존의 검증된 ComfyUI 런타임을 Benchmark Lab에서 사용할 수 있습니다. 네이티브 T2I에는 명시적인 single-file Transformer, Text Encoder, VAE가 필요합니다. 지원되지 않는 조합은 해당 작업만 실패하고 나머지 배치는 계속됩니다. float 복원은 별도의 품질/디버그 모드이며 시간과 VRAM은 네이티브 INT8 성능이 아닙니다.
